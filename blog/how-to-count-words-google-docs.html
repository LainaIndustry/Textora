How to Count Words in Google Docs

By the Textora Editorial Team Approximately 900 words About 5 minutes to read

Google Docs has built-in word count tools, but they hide some useful options. This guide shows how to find them and what they include.

The Fastest Way: Status Bar

Google Docs shows the word count at the bottom of the document window, near the left or center depending on the layout. If you see a number followed by "words," you're looking at the live count for the whole document.

If you don't see it, click on the status bar area or check the View menu. The visibility setting varies by version.

The Word Count Dialog

To open the word count dialog:

  1. Click Tools in the top menu.
  2. Select Word count.
  3. A dialog opens with pages, words and characters, with and without spaces.

You can also press Ctrl + Shift + C (Windows) or Cmd + Shift + C (Mac) as a shortcut.

Counting a Selection

Select the text you want to count, then open the word count dialog. It will show the count for the selection alongside the whole document. This is useful for counting a specific section without copying it elsewhere.

The status bar count also updates to show the selection count when text is selected, in most versions.

What the Count Includes

Google Docs word count includes body text, headings and lists. By default, it does not count footnotes unless you enable the "Display word count while typing" option and configure it. Check the dialog for a checkbox that controls whether footnotes are included.

Headers and footers are generally not counted in the main body count. If your word limit includes them, you'll need to count them separately or copy them into the body for counting.

Characters, Not Just Words

The same dialog shows character count with and without spaces. If your assignment or platform has a character limit, this is the number you need. Character counts are useful for:

  • Meta descriptions and titles.
  • Social media posts.
  • Form fields with hard limits.
  • Translation billing, which is often per character.

Displaying Live Counts While Typing

The word count dialog has a checkbox labelled "Display word count while typing." Enabling it shows a live counter in the corner of the document as you type. This is useful for staying close to a target, though it can be distracting during drafting.

Limitations of Google Docs Word Count

  • Footnotes: inclusion depends on settings.
  • Comments: not counted in the main body.
  • Headers and footers: not included in the body count.
  • Non-Latin scripts: tokenization depends on the language settings.
  • Special characters: emoji and symbols may behave differently from plain text.

When to Use an External Word Counter

Google Docs' built-in count is convenient, but it doesn't provide statistics like unique word count, reading time, sentence count or keyword density. For deeper analysis, copy the text into the Textora Word Counter. This is also useful when:

  • You need reading time estimates.
  • You want to check keyword frequency.
  • You need sentence or paragraph statistics.
  • You want a second count to confirm the first.

Copying Text Safely

When copying from Google Docs to another tool, formatting may carry over as invisible characters. Paste as plain text (Ctrl/Cmd + Shift + V) to avoid stray characters. After pasting, run the Remove Extra Spaces tool if the count looks off.

Conclusion

Google Docs provides solid word and character counts through its status bar and word count dialog. For deeper statistics, an external tool complements the built-in count. Use the Textora Word Counter when you need reading time, unique words or sentence structure, and use the Google Docs count when you just need a quick number.

Frequently Asked Questions

Does Google Docs count footnotes?

By default, footnotes are often excluded from the main body count. Check the word count dialog for the option to include them.

How do I count just part of a document?

Select the text, then open the word count dialog. It shows the selection count alongside the whole document count.

Does Google Docs count headers and footers?

Generally no. If they need to count, copy them into the body or count them separately.

Is there a keyboard shortcut?

Yes: Ctrl + Shift + C on Windows or Cmd + Shift + C on Mac opens the word count dialog.
