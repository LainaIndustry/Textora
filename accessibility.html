Accessibility Statement

Last updated: [DATE TO BE SET BY SITE OWNER]

Our Accessibility Goals

This site aims to be usable by people with a wide range of abilities and assistive technologies. Specific goals include:

  • Keyboard navigation for all interactive controls.
  • Visible focus indicators.
  • Clear labels and instructions for all forms and inputs.
  • Color contrast that meets WCAG guidelines for text.
  • Respect for reduced-motion preferences.
  • Responsive layouts that work at zoom levels up to 200%.

Keyboard Support

The mobile navigation menu can be opened and closed with the keyboard. The Escape key closes the menu when it is open. All buttons and form fields can be reached with the Tab key. A skip link at the top of each page jumps to the main content.

Labeling

Inputs and controls have associated labels. Icons that convey meaning are marked for assistive technology. Decorative icons are hidden from screen readers.

Color and Contrast

Text and interface elements are designed to meet common contrast guidelines. Users can override colors through browser or operating system settings.

Known Limitations

Some interactive tools produce results that update without a full page reload. Live regions are used where possible to announce updates, but some updates may not be announced automatically in all browsers. Users who rely on screen readers may prefer to trigger updates manually (for example, by pressing a button) where the tool provides one.

Reporting Accessibility Problems

If you encounter an accessibility barrier, please describe it in an email to contact@YOURDOMAIN.com. Include the page, the device and browser you used, and any assistive technology involved. Reports help improve the site.

Site owner note: Verify contrast ratios and keyboard support after any design change. Consider testing with a screen reader and keyboard-only navigation before launch.
