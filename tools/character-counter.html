What the Character Counter Measures

The counter reports two values: characters including spaces and characters excluding spaces. Both are based on JavaScript string length, which counts Unicode code units. Most common Latin characters count as one unit; some emoji and rare symbols use two or more code units.

Common Character Limits

  • Meta description: often around 150–160 characters.
  • Page title: often around 50–60 characters.
  • Social posts: platform-specific and subject to change.
  • Headline or subject line: varies by platform.

Always check the current official limit for the platform you are using.

Frequently Asked Questions

Do line breaks count as characters?

Yes. Line breaks are characters and are included in the total length. They are removed in the “no spaces” count.

Do emoji count as one character?

Not always. Many emoji are represented by more than one Unicode code unit, so they may increase the count by more than one.

Why does the count differ from another tool?

Tools may count Unicode code units, grapheme clusters or bytes. Small differences are expected for emoji and some non-Latin scripts.
