Text Sorter

Sort lines alphabetically, numerically, by length or in reverse.

Sorted result

Sorting Rules

Alphabetical sorting uses locale-aware comparison. Numeric sorting uses parseFloat, so non-numeric lines may sort unpredictably. Length sorting compares the number of characters in each line.

Common Uses

  • Alphabetizing name or keyword lists.
  • Sorting numeric IDs or prices.
  • Ordering lines by length for a visual check.

Frequently Asked Questions

Is alphabetical sorting case-sensitive?

It uses locale comparison, which typically places uppercase and lowercase letters near each other. Exact order can vary by browser locale.

Can I sort comma-separated values?

Only if each value is on its own line. Convert commas to line breaks first with Find and Replace.
