How Paragraphs Are Counted

A paragraph is a block of text separated from another block by at least one blank line. Lines that contain only spaces are ignored. A single line of text with no blank line is counted as one paragraph.

Using the Paragraph Count

Very long paragraphs can be hard to read on screen. If you have a low paragraph count relative to word count, consider adding paragraph breaks at natural transitions. Use the Remove Extra Spaces tool to clean up inconsistent blank lines first.

Frequently Asked Questions

Does a single line break create a new paragraph?

No. This tool treats a blank line as the separator. A single newline within a block is treated as part of the same paragraph.

Can I count list items as paragraphs?

List items on separate lines without blank lines between them are counted as one paragraph. Add a blank line between items if you want each item counted separately.
