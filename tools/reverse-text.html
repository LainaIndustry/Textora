Reverse Text

Reverse characters, words or line order in one click.

Result

Reverse Modes

  • Characters: reverses the entire string, including spaces.
  • Words: reverses the order of whitespace-separated words.
  • Lines: reverses the order of lines.

Uses

Text reversal is mainly useful for puzzles, testing and formatting checks. It is not a security mechanism.

Frequently Asked Questions

Does reversing handle Unicode correctly?

It reverses JavaScript string code units. Emoji and combined characters may break apart. For plain Latin text it works as expected.

Can I reverse each word but keep word order?

Not directly. This tool reverses whole characters, word order or line order.
